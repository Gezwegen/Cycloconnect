# Contributing to CycloConnect

Thank you for your interest in contributing to **CycloConnect**! We welcome contributions, bug reports, and feature requests from the community to help make this desktop companion even better for Mio Cyclo users.

---

## 📜 Code of Conduct

Please treat everyone with respect and kindness. We aim to keep CycloConnect an open, welcoming, and collaborative space for all cyclists and developers.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
Before opening a new issue, please search the existing issues to see if the bug has already been reported.

When creating a bug report, please include:
- **Operating System:** (e.g., Windows 10 / 11)
- **Mio Device Model:** (e.g., Mio Cyclo 210, 505 HC)
- **Steps to Reproduce:** Clear, step-by-step instructions on how to replicate the issue.
- **Expected vs. Actual Behavior:** What you expected to happen vs. what actually happened.
- **Logs / Screenshots:** Any relevant error messages or UI screenshots.

### 2. Suggesting Features
Have an idea to improve CycloConnect? Feel free to open an issue with the label `enhancement`.
- Describe the problem or limitation you are trying to solve.
- Clearly explain your proposed feature or improvement.

### 3. Submitting Pull Requests (PRs)
We welcome pull requests! To submit a contribution:
